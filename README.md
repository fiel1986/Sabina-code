# 🎨 Sabina/Code — Editor de Código con IA

**Un editor de código completo integrado con inteligencia artificial para autocompletado y generación de código. Funciona 100% en tu navegador, sin servidor.**

---

## ✨ Características

- ✍️ **Autocompletado con IA** — Sugerencias fantasma en tiempo real (TAB para aceptar)
- 💬 **Chat integrado** — Pide código y se inserta automáticamente en el editor
- 🧠 **5 modelos de IA** — Llama 3.3 70B, GPT-OSS 120B, Qwen 3.8 27B, GPT-OSS 20B, Llama 3.1 8B
- 🌐 **6 lenguajes** — Python, JavaScript, HTML, C++, TypeScript, JSON
- 📥 **Ejecutar JS/HTML** — Preview en vivo en el panel inferior
- 💾 **Descargar código** — Exporta como archivo
- 🔒 **100% privado** — Tu API key se guarda solo en tu navegador (localStorage)
- ⚡ **Sin instalación** — Un solo archivo HTML

# 🎨 Sabina/Code — AI Code Editor

**A complete code editor integrated with artificial intelligence for autocompletion and code generation. Runs 100% in your browser, no server needed.**

---

## ✨ Features

- ✍️ **AI Autocompletion** — Ghost text suggestions in real-time (TAB to accept)
- 💬 **Integrated Chat** — Ask for code and it inserts directly into the editor
- 🧠 **5 AI Models** — Llama 3.3 70B, GPT-OSS 120B, Qwen 3.8 27B, GPT-OSS 20B, Llama 3.1 8B
- 🌐 **6 Languages** — Python, JavaScript, HTML, C++, TypeScript, JSON
- 📥 **Run JS/HTML** — Live preview in the bottom panel
- 💾 **Download Code** — Export as a file
- 🔒 **100% Private** — Your API key is saved only in your browser (localStorage)
- ⚡ **No Installation** — Single HTML file

---

## 🚀 Getting Started

### Step 1: Get your Groq API Key

1. Go to **[console.groq.com/keys](https://console.groq.com/keys)**
2. Click **"Create API Key"**
3. Give it a name (e.g., "Sabina/Code") and copy the key (starts with `gsk_`)
4. The key is **free** — Groq provides free credits to get started

> 💡 **No credit card required.** Free credits are enough for personal use.

### Step 2: Open the Editor

```bash
git clone https://github.com/tu-usuario/sabina-code.git
cd sabina-code

Configure

Paste your Groq key in the "gsk_... Groq API key" field
Click "Guardar" (Save)
Select the AI model you want to use
Start coding or chatting!

📋 How to Use

Ghost Autocompletion
Type code in the editor
Wait ~1 second — the AI will generate suggestions
Press TAB to accept the suggestion
Press ESC to dismiss
Code Chat
Type in the chat panel (e.g., "write a function that sorts an array")
The AI responds with code in a markdown block
Click → Insert into editor or let it auto-insert
Check "Auto-insertar" to always insert without confirmation
Run Code
HTML and JavaScript run in the bottom panel
Python, C++, TypeScript, JSON → use "Download" and run them locally
